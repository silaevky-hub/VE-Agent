# База выученных уроков Value Engineering

## Статус

Рабочая база принятых VE-инициатив. На дату создания записей нет.

Правила состава, пополнения и использования базы определены в `07_База_выученных_уроков.md`. В эту базу включаются только инициативы, подтверждённые оператором для включения.
