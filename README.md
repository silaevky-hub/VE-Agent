# VE Agent

VE Agent помогает провести Value Engineering анализ инвестиционного проекта: подготовить исходные данные, сформировать WBS и исходный базис, проверить минимальные элементы по пяти рычагам, объединить результаты и подготовить отчет.

## Начало работы

Создайте на компьютере папку VE-Agent. В приложении выберите **Codex и локальную работу на этом компьютере**, создайте локальный проект с этой папкой и откройте установочную сессию. Одноименный проект ChatGPT и выбор модели сами по себе не переключают вид сессии.

Скачайте [руководство пользователя PDF](https://github.com/silaevky-hub/VE-Agent/releases/download/v3.0.0/VE-Agent-User-Guide.pdf), передайте агенту и скопируйте поручение из раздела 1. Агент выполнит восемь шагов SETUP: запросит точечные разрешения, проверит Python 3.12, скачает исходный ZIP и выполнит установку. Python может уже входить в комплект среды. Полный доступ ко всему компьютеру в успешном пилоте не потребовался; команды выполняет агент.

После установки следующим сообщением в той же сессии попросите проверить **все пять Skills VE Agent** по шагу 7 SETUP.md. По каждому отдельно нужны результаты: файлы установлены и соответствуют v3.0.0 по манифесту, навык виден среде, подключение в этой сессии подтверждено. Непроверенное отмечается "не подтверждено" с причиной и следующим действием. Итог сохраняется в SETUP_RESULT.md. Эта проверка не запускает подготовку данных, WBS, VE-анализ или агрегацию и не меняет базу. Новый чат и повторная установка по умолчанию не нужны.

Рекомендуемый профиль на ноябрь 2026 года - **GPT-6.2 Sol, высокое усилие (High)**. Можно выбрать другую модель по функциональным требованиям руководства. Все команды выполняет установочная сессия; оператор выбирает настройки, подтверждает необходимые доступы и при необходимости вводит пароль в системном окне macOS. Ручной ввод команд в Terminal не требуется.

[Принятые эталоны для просмотра](https://silaevky-hub.github.io/VE-Agent/) - те же формы, на которые ссылается руководство. Пример отчета 0.1.4 не изменен.

## Проверенная среда и границы

Установка проверена в Codex на macOS arm64 с Python 3.12. Windows, Mac с Intel и другие среды в эту поставку не входят. Установка не запускает новый анализ автоматически; роли, модели, инструменты и периметр определяются для конкретной задачи.

Каждый оператор ведет свою локальную базу инициатив. Новые записи вносятся после принятого отчета и отдельного разрешения. Включение гипотезы в реестр не подтверждает ее техническую реализуемость; открытые условия сохраняются. Текущий технический трек не включает расчет экономического эффекта.
