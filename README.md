# VE Agent

VE Agent помогает провести Value Engineering анализ инвестиционного проекта: подготовить исходные данные, сформировать ИСР и исходный базис, проверить минимальные элементы по пяти рычагам, объединить результаты и подготовить отчет.

## Начало работы

Создайте на компьютере папку VE-Agent, подключите ее к отдельному проекту Codex и откройте рабочую сессию. Скачайте [руководство пользователя в PDF](https://github.com/silaevky-hub/VE-Agent/releases/download/v3.0.0/VE-Agent-User-Guide.pdf) и передайте его своему агенту. Руководство содержит пять первых действий оператора, полную инструкцию SETUP.md и восемь самостоятельных шагов установочного агента. Если Python 3.12 отсутствует, агент организует его установку; необходимые системные права или ручные действия запрашивает у оператора.

Ручной ввод команд в Terminal не требуется.

## Проверенная среда и границы

Установка проверена в Codex на macOS arm64 с Python 3.12. Windows, Mac с Intel и другие среды в эту поставку не входят. Установка не запускает новый анализ автоматически; роли, модели, инструменты и периметр определяются для конкретной задачи.

Каждый оператор ведет свою локальную базу инициатив. Новые записи вносятся после принятого отчета и отдельного разрешения. Включение гипотезы в реестр не подтверждает ее техническую реализуемость; открытые условия сохраняются. Текущий технический трек не включает расчет экономического эффекта.
